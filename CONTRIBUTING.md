# Contributing

PuzzleVerse-3D is a university project foundation. Contributions should be small, reviewable, evidence-based, and consistent with the current implementation status.

## Workflow

1. Open or update an issue.
2. Create a branch using `feature/`, `fix/`, `docs/`, `test/`, or `chore/`.
3. Implement only the agreed scope.
4. Run the relevant local checks.
5. Open a pull request using the template.
6. Address review comments and merge only after required checks pass.

## Standards

Do not commit secrets, private user images, unlicensed assets, fabricated results, or claims that a planned feature is implemented. Add tests for behavior changes. Document new datasets, models, and decisions.

## Commit messages

Use imperative, scoped messages such as `docs: add computer vision evaluation plan` or `feat(backend): add session schema`.

# GitHub workflow

Use `main` as the stable integration branch. Recommended branches are `feature/feature-name`, `fix/bug-name`, `docs/documentation-name`, `test/test-name`, and `chore/maintenance-name`. Protect `main` after the team agrees on required checks. Use issues, pull requests, review, and passing CI. A Projects board should contain Backlog, Todo, In Progress, In Review, and Done; if not created by the owner, use the task backlog as the source of truth.
